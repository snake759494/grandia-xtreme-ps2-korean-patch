# 그란디아 익스트림 PS2 한글패치

PS2 일본판 **그란디아 익스트림(グランディア エクストリーム, SLPM-65089)**용 비공식 한국어 패치입니다. **대사 5,002종 전체**, **아이템·마법·스킬 이름과 4줄 설명·메뉴·세이브 화면** 등 시스템 문자열 3,048종, **적 이름·적 기술 이름 340종**, **전투 메시지**, **콘서트·복권 미니게임** 문자열과, **타이틀 메뉴·전투 결과·능력치 변화·지역 이름·튜토리얼 화면** 등 그림 글자를 한국어로 바꿨습니다. PCSX2용 **16:9 와이드 패치**도 함께 배포합니다. 현재 배포판은 **v1.1 (2026-11-07)**입니다.

[패치 다운로드](https://github.com/snake759494/grandia-xtreme-ps2-korean-patch/releases/latest) · [기술 설명](docs/TECHNICAL.md) · [재빌드](docs/BUILD.md) · [변경 기록](CHANGELOG.md) · [권리 안내](RIGHTS.md)

릴리즈 첨부 파일은 한글패치 **Grandia_Xtreme_PS2_KO_v1.1.xdelta**와 와이드 패치 **SLPM-65089_692AE2A7.pnach**입니다. 저장소에는 제작 소스와 한국어 번역만 공개합니다. 원본·완성 디스크 이미지, 추출한 게임 파일, 일본어 원문, 글꼴 파일, 외부 실행 파일은 포함하지 않습니다. GitHub가 자동으로 만드는 Source code ZIP/TAR는 저장소 소스를 압축한 것이며 게임 파일이 아닙니다.

## 게임 소개 및 대상 버전

『그란디아 익스트림』은 게임아츠가 개발하고 에닉스가 2002년에 낸 PS2용 RPG입니다. 그란디아 시리즈의 전투 시스템을 이어받아, 정령 폭주를 막기 위해 모인 레인저 에반과 동료들이 여러 유적 던전을 공략하는 던전 탐색 중심의 작품입니다.

이 패치는 **PS2 일본판 SLPM-65089의 DVD ISO**에만 적용됩니다. 파일 이름보다 아래 표의 크기와 해시가 일치하는지가 중요합니다.

## 패치 적용 방법

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Grandia Xtreme (Japan, Asia).iso'
```

위 표와 다르면 적용을 중단하세요. CHD, CSO, 압축 이미지에는 적용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `Grandia_Xtreme_PS2_KO_v1.1.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `Grandia Xtreme (Korean).iso`).

xdelta는 호환성을 위해 압축·2차 압축·파일 경로 헤더 없이 만들었습니다. 그래서 파일이 큽니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\Grandia Xtreme (Japan, Asia).iso' '.\Grandia_Xtreme_PS2_KO_v1.1.xdelta' '.\Grandia Xtreme (Korean).iso'
```

원본판 세이브 스테이트는 쓰지 마세요. 메모리 카드 세이브는 원본판과 호환됩니다. v1.1부터 실행파일의 메뉴 문자열을 번역했기 때문에 PCSX2의 게임 CRC가 `692AE2A7`로 바뀝니다. 원본판(`958A6461`)용 치트·패치 파일은 자동으로 적용되지 않습니다.

## 16:9 와이드 패치 사용법 (PCSX2 2.x)

`SLPM-65089_692AE2A7.pnach`는 3D 화면을 16:9로 넓히는 PCSX2용 패치입니다. 이 게임에는 와이드 화면 옵션이 없습니다. v1.1 한글판은 실행파일이 바뀌어 게임 CRC가 `692AE2A7`이므로, 원본판(`958A6461`)용 PCSX2 내장 와이드 패치는 **자동으로 나타나지 않습니다**. 이 파일은 PCSX2 배포 패치 모음(pcsx2_patches)의 원본판 패치(Arapapa 제작)를 한글판 CRC로 옮긴 것이며, 패치 내용은 같습니다.

**pnach 파일로 켜기**
1. PCSX2에서 한글판 ISO를 한 번 부팅하고 종료합니다. 로그(도구 > 로그 창 보기)나 게임 목록 속성에서 CRC가 `692AE2A7`인지 확인합니다.
2. `SLPM-65089_692AE2A7.pnach`를 PCSX2 `patches` 폴더에 복사합니다. 파일 이름을 바꾸지 마세요.
   - 설치판 기본 위치: `문서\PCSX2\patches`
   - 포터블판: PCSX2 폴더 안의 `patches`
   - 정확한 위치는 설정 > 폴더에서 "패치" 항목으로 확인할 수 있습니다.
3. 게임 목록에서 이 게임을 우클릭하고 **속성 > 패치**를 엽니다. **Widescreen 16:9**에 체크합니다.
4. 같은 속성 창의 **그래픽 > 화면**에서 **화면비(Aspect Ratio)**를 **와이드스크린 (16:9)**으로 바꿉니다. pnach의 `gsaspectratio=16:9` 줄 때문에 패치를 켜면 화면비가 자동으로 바뀌기도 합니다.
5. 게임을 시작하면 화면 위에 "게임 패치가 활성화되었습니다"가 뜹니다. 필드·전투의 3D 시야가 좌우로 넓어지고 캐릭터가 가로로 늘어나 보이지 않습니다.

주의
- 원본판(일본어)을 실행할 때는 PCSX2 내장 패치(속성 > 패치 > Widescreen 16:9)를 쓰면 됩니다. 이 파일은 한글판 v1.1 전용입니다.
- 3D 화면만 보정됩니다. 대화창·메뉴·전투 HUD 같은 2D 화면과 동영상은 가로로 늘어나 보입니다.
- 패치가 목록에 없으면 파일 이름의 CRC(`692AE2A7`)와 실제 게임 CRC가 같은지, `patches` 폴더 위치가 맞는지 확인하세요.
- 와이드 패치를 끄려면 속성 > 패치에서 체크를 풀고 화면비를 4:3으로 되돌립니다.

## 한글화 범위

- 대사 5,002종: 필드·이벤트·식당 대화, 마을 사람, 튜토리얼, 시스템 안내 등 모든 필드 스크립트 메시지
- 시스템 문자열 3,048종: 아이템·장비·마나 에그·스킬 북·스킬·마법 이름, 아이템·마법·스킬 설명 328개(4줄 묶음), 지명, 상점·기술자·세이브/로드·메모리 카드 안내, 메뉴·작전·장비·스테이터스 화면, 대화창 화자 이름표
- 전투: 적 이름·적 기술 이름 340종, 작전 이름·명령·결과 메시지
- 미니게임: 콘서트(곡 선택·캐로 배치)와 복권 노인 대사
- 그림 글자: 타이틀 메뉴(새로 시작·이어하기·설정), 전투 능력치 변화 표시, 연속마법·작전변경 라벨, 지역 이름, 전투 결과 화면(획득 포인트·경험치·금액), 필살기·합체기 피니시 배너, 튜토리얼 설명 화면
- 글꼴: 나눔스퀘어 네오
- 원문 유지: 로고, 저작권 표기, 영문 UI 글자, 오프닝 동영상 속 스태프 크레디트, 쓰이지 않는 디버그·더미 문자열

## 알려진 한계

- 와이드 패치는 3D 화면만 보정하며, 2D 화면과 동영상은 가로로 늘어납니다.
- 적 이름과 미니게임 문자열은 원문 바이트 수 안에 넣어야 해서 일부를 줄여 적었습니다(예: 잠자리개구리 → 잠개구리).
- 오프닝 동영상 속 스태프 크레디트는 영상에 그려진 글자라 바꾸지 않았습니다.
- PCSX2에서 타이틀, 오프닝 이후 기숙사까지의 대사, 메뉴, 아이템 설명을 확인했습니다. 전투 화면의 적 이름·기술 이름과 두 미니게임은 실제 화면에서 확인하지 못했고(데이터가 한국어로 바뀐 것만 확인), 실기에서의 동작도 확인하지 못했습니다. 문제가 있으면 이슈로 알려 주세요.
