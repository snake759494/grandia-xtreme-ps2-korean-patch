# 기술 설명

## 디스크와 압축
- 디스크는 ISO9660 DVD입니다. 바꾼 파일은 원래 섹터에 들어가면 그 자리에 쓰고, 커지면 볼륨 끝에 붙인 뒤 디렉터리 레코드와 PVD 볼륨 크기를 고칩니다(`tools/isofs.py`). 실행파일(`SLPM_650.89`)은 건드리지 않습니다.
- `FIELD/*.MDT`, `SYS/GRXSYS.PAC` 등은 16바이트 헤더를 키로 XOR 한 LZSS(2KB 창, 시작 위치 0x7DE)로 압축되어 있습니다. `tools/lz.py`가 풀고 `tools/lzfast.py`(numba)가 다시 압축합니다. 다시 압축할 때 헤더의 키 값은 원본 것을 씁니다.

## 문자 코드
- 문자는 글리프 번호를 바이트로 적습니다. 번호 < 208은 1바이트(`글리프+0x20`)이고, 그 이상은 둘째 바이트가 0xF0 이상인 2바이트입니다(`tools/gxtext.py`).
- 0x1F는 줄바꿈, 0x00은 끝, 0x20 미만의 나머지 바이트는 표정·화자·대기·페이지 넘김 같은 제어 코드입니다. 번역 파일에는 `|`와 `{1A}` 같은 토큰으로 적었습니다.
- 글꼴은 `GRXSYS.PAC` 0번 항목의 16×16 4bpp 글리프 2,108칸과 글리프별 좌우 폭 표(0xFDA00)입니다. 한글은 번역에 쓰인 글자만 원본 한자 칸에 덮어씁니다. 자주 쓰는 한글이 1바이트 번호를 받도록 사용 빈도 순으로 배치합니다(`tools/ko.py`, `tools/mkfont.py`).
- 일부 메뉴 문자열과 미니게임 문자열은 바이트가 아니라 u16 글리프 번호 배열로 들어 있습니다.

## 대사 (FIELD/*.MDT)
- 각 MDT의 0x78에 스크립트 크기·위치가 있습니다. 스크립트 안의 메시지 명령(0x17 …)을 해석해 대사 5,002종을 뽑습니다(`tools/ext_mdt.py`, `tools/msg.py`, `tools/vm.py`).
- 번역이 원문보다 길어지므로 스크립트를 명령 단위로 다시 조립하고 분기·점프 주소를 모두 고칩니다(`tools/mdtbuild.py`).

## 시스템 문자열 (SYS/GRXSYS.PAC)
- 96개 항목으로 된 묶음 파일입니다. 33·35·36·41번 항목에 아이템·마법·스킬 이름과 설명, 메뉴 문자열이 포인터 표와 함께 들어 있습니다(`tools/ext_sys.py`, `tools/sysbuild.py`).
- 아이템·마법·스킬 설명(33·35·41번)은 첫 줄에만 포인터가 있고, 게임이 그 뒤에 이어진 NUL 종료 문자열 4개를 한 설명으로 읽습니다. 그래서 설명 328개를 4줄 묶음으로 번역하고 함께 옮깁니다(`tools/sysgroups.py`). 첫 줄만 옮기면 다른 설명의 2~4번째 줄이 딸려 나옵니다.
- 49번 항목의 메뉴·세이브 화면 문자열, 화자 이름표, 일부 짧은 문자열은 u16 배열이라 같은 칸 안에서 바꿉니다(`tools/menu_ko.py`).

## 전투
- `BATTLE.BIN`의 고정 칸 문자열(작전 이름·명령·결과 메시지 47종)은 칸 크기 안에서 바꿉니다(`tools/bintext.py`).
- 적 이름과 적 기술 이름 340종은 각 필드 MDT의 전투 데이터 안에 있습니다. 블록마다 "일반 공격" 문자열로 시작하고 문자열마다 상대 포인터가 따로 있어, 원문 바이트 수 안에 한국어를 넣고 나머지는 0으로 채웁니다(`tools/enemy.py`). 칸이 모자라는 이름은 줄인 표기를 씁니다.

## 미니게임
- 콘서트(2008·3034.MDT)와 복권(2090·E490.MDT) 미니게임 문자열은 필드 코드 안의 u16 배열입니다. 원문 길이 안에서 바꿉니다(`tools/code16.py`).

## 그림 글자
- 타이틀 메뉴, 전투 능력치 변화 표시, 연속마법·작전변경 라벨, 지역 이름 그림, 전투 결과 화면(획득 포인트·경험치·금액), 필살기·합체기 피니시 배너, 튜토리얼 설명 화면을 다시 그렸습니다(`tools/texjobs.py`, `tools/texpaint.py`, `tools/tex.py`).
- 같은 텍스처가 여러 파일에 복사되어 있어서, 텍스처 블록의 MD5로 같은 그림을 모두 찾아 바꿉니다(`tools/texapply.py`, `work/texlist.txt`).

## 원문 없이 재빌드하기
- `translation/pub/*.tsv`는 `ID, 원문 SHA-1 앞 16자리, 번역`입니다. `tools/prepare.py`가 원본에서 원문 후보를 모두 뽑아 해시로 맞춰 `translation/src`(원문)와 `translation/ko`(번역)를 만듭니다.
- 코드 안 표(메뉴·전투·미니게임)의 일본어 원문은 `J('해시')`로 적었습니다. `tools/jppool.py`가 원본 파일의 문자열로 `work/jp_pool.tsv`를 만들어 원문을 찾습니다.
- `translation/charmap_jp.txt`는 글리프 번호 → 문자 대응표(글꼴 순서)입니다.
